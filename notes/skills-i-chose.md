# Skills I chose

Searched skills.sh on 2026-10-30 with `npx skills find` for: email marketing, email sequence, campaign plan, resend. GitHub stars were checked the same day.

## Use these

1. **Anthropic's marketing plugin** (`anthropics/knowledge-work-plugins`, 33,972 stars, official Anthropic organization). Use it for planning and writing campaigns. It has `campaign-plan`, `email-sequence` and `brand-review`, which match what we need. It didn't come up in the skills.sh search, because it's installed as a Claude Code plugin rather than with `npx skills`.
2. **Resend's own skills** (`resend/resend-skills`, 208 stars, official Resend organization). Use these for sending email. The publisher is the company that runs the email service, so the skill matches how Resend actually works. The main skill is `resend` (23.9K installs). Resend also publishes `email-best-practices` (146 stars) and `react-email` (19,894 stars).

A runner-up: `coreyhaines31/marketingskills` (57,466 stars) has well-used copywriting and email skills. It's run by one person rather than a company, so it's fine for ideas but isn't our first choice. Its `email-sequence` skill no longer shows up; the search now lists one called `emails`.

## Avoid these

1. **`mbfinotti/advertising-skills`**: about 23,000 installs but only 2 GitHub stars, from one personal account. Install counts that far out of line with stars are a warning sign that the numbers may be inflated. It's also about paid ads, which we don't use.
2. **`open.feishu.cn@lark-mail`**: the top result for "email marketing", with 830K installs. Its publisher is a website address, not a GitHub repository, so there are no stars or code history to check. It's also for managing a Lark/Feishu mailbox, not for writing marketing emails. High installs alone don't make it the right tool or a trusted one.

## How I decided

1. **Who publishes it.** Prefer the official company (anthropics, resend) or a well-known maintainer over an unknown account.
2. **Whether stars and installs agree.** Installs can be faked. A repository with real stars, recent updates and an organization owner is harder to fake.
3. **Whether it fits the job.** Read what the skill actually does, and confirm it still exists under that name, before installing it.
