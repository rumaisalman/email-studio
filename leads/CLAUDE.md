# Rules for the leads folder

These rules apply only to files in `leads/`.

- Everyone in these lists is a made-up practice person. None of them are real.
- Never add real people or real email addresses.
- Every row needs a consent value. Don't leave the `consent` column empty.
- Never change the `@example.com` addresses. That domain can't receive mail, so no real person is ever emailed.
- Everyone on our email lists must be 16 or older. Don't add anyone younger.
